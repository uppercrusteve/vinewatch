# 示例备份

`demo-backup.json` 是一份可直接导入的 **合成演示** 备份：2 个虚构地块、5 条记录，覆盖有坐标、无坐标、带换行/逗号/引号的备注，以及 JSON 导入的路径。日期为 2025 年生长季，地块与坐标均非实测。

## 导入

1. 打开应用（本地 `npm run dev` 或在线演示）。
2. 切到「导出」标签。
3. 在「导入 JSON 备份」中点「选择备份文件」，选本文件。
4. 状态行会报告导入数量；重复导入相同文件时，记录会按 ID 与内容指纹跳过。

也可先用「导出 → JSON 全量备份」查看同一 schema 的真实结构，再与本文件对照。

## 注意

- 导入只合并，不覆盖现有数据；导入前建议先导出自己的备份。
- 无坐标的记录不会出现在 GeoJSON 中，但仍会出现在 CSV 与 JSON 里。
- 本文件不含照片；照片在 JSON 备份中是 `data:image/jpeg` 字符串。
